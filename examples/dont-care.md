# مثال‌های dont care

مثال‌های ۲۴ تا ۳۲ در فهرست Camera Lab در دسترس‌اند. صحنه‌های قبلی را با پرامپت‌های کم‌جزئیات استفاده می‌کنند تا تفاوت ناشی از درخواست دوربین را مقایسه کنیم. CSL مرجع فقط خواسته‌های پرامپت را مشخص می‌کند.

## پخش و مقایسه

1. با `npm run visualizer` ویژوالایزر را اجرا کنید.
2. یکی از لینک‌های جدول را باز کنید یا شمارهٔ مثال را از فهرست صحنه‌ها انتخاب کنید.
3. **Replay bundled** را بزنید و در **Director POV** نتیجه را ببینید. این مسیر به مدل یا API key نیاز ندارد.
4. در نمای **God View** مسیر و فاصلهٔ دوربین را بررسی کنید. برای تست ترجمهٔ خود پرامپت، پس از تنظیم مدل، **Run full pipeline** را بزنید و Draft و Timeline را با CSL مرجع مقایسه کنید.

## مقایسه‌های مهم

- **۲۴ و ۲۵:** صحنه یکسان است؛ در ۲۵ فقط شعاع ۴ متر اضافه شده است. شعاع در پلان کامپایل‌شدهٔ ۲۴ نباید هدف عددی داشته باشد. شباهت اتفاقی شعاع خروجی‌ها به معنی بسته‌بودن این پارامتر نیست.
- **۲۴ و ۲۶:** در ۲۶ فقط جهت آرک و سمت راست قاب صریح شده‌اند؛ قرارگیری سمت راست نباید با مرکزکردن پیش‌فرض جایگزین شود.
- **۲۴ و ۲۷:** در ۲۷ کلوزآپ صورت مهم است و بریدن بدن از قاب قابل انتظار است. لاس پیش‌فرض نباید برای جا دادن کل بدن، کلوزآپ را خراب کند.
- **۲۸:** قید `subjectAware` فقط هویت سوژه دارد. هیچ `shotSize` یا موقعیت در کادر تعیین نشده، ولی ترجیح دیده‌شدن سوژه باید فعال باشد.
- **۳۰ و ۳۱:** در ۳۰ هر دو سوژه همزمان مهم‌اند؛ در ۳۱ کاتِ ثانیهٔ ۴ محدودهٔ اهمیت هر سوژه را جدا می‌کند.
- **۳۲:** تنها لنز اولیه و ضریب زوم مشخص‌اند. انتظار رابطهٔ تقریبی ۷۰ به ۳۵ درجه را داریم؛ موقعیت و جهت آغازین نباید قید ساختگی بگیرند.

لاس‌ها نرم‌اند؛ فاصله، زاویه و جای سوژه می‌توانند با ایمنی، نرمی حرکت و سایر خواسته‌ها مصالحه کنند. آستانه‌های کیفیت و مثال‌های نامشخص، مقدار عددی ثابت برای خروجی تعیین نمی‌کنند.

## بازتولید خروجی‌ها

```sh
npm run generate:dont-care
```

این دستور فقط مثال‌های ۲۴ تا ۳۲ را با CSL مرجع و ۵۰۰ iteration بهینه می‌کند. خروجی‌ها کنار سایر مثال‌ها در `web/public/trajectories/optimized/` نوشته می‌شوند. تشخیص‌ها و لاس‌های کامپایل‌شده هم در `shared/optimized/output_24.json` تا `output_32.json` ذخیره می‌شوند.

برای بازتولید یک مثال با بودجهٔ دیگر:

```sh
npm run generate:dont-care -- --example example-24 --iterations 1000
```

همین مثال را با دستور عمومی پروژه هم می‌توان بازتولید کرد:

```sh
npm run generate:trajectories -- --example example-24 --iterations 1000
```

CSL و توضیح همهٔ نمونه‌ها در [dont-care-examples.ts](../src/data/dont-care-examples.ts) است. صحنه‌ها نسخه‌های مستقل از مثال‌های ۱۵، ۱۶ و ۱۷ هستند و حرکت اشیای آن‌ها یکسان مانده است.
