# Video scenes

Environments reconstructed from real footage by the SAM3 + SpatialTrackerV2 notebook, and the
camera shots generated for them. Kept apart from `web/public/environments/` on purpose:
`scripts/audit-environments.ts` asserts that folder holds exactly `stadium`, `factory` and the
manifest, and `generate-two-environments.py` deletes anything else in it.

```
video/<scene>/
  source/scene.environment.json   raw notebook output (relative scale) - never edited
  source/scene.tracking.json      notebook sidecar: real camera path + intrinsics, tracks
  environment/                    generated: calibrated (metres) copy + its own manifest.json
  scene.json                      generated: metres-per-unit factor, source hash
  shots/<shot>/                   one folder per shot; file names match examples/cinematic-suite/<example>/
    draft-csl.json  binding.json  csl.json  keyframes.json
    trajectory.json timeline.json diagnostics.json metadata.json
    ttm/                          (next step) motion_signal.mp4, mask.mp4, first_frame.png, settings
```

## Workflow (repo root)

```bash
# 1. import the notebook outputs and list entities with their size in tracker units
npm run video:register -- --scene the-pianist \
  --environment path/scene.environment.json --tracking path/scene.tracking.json
# 2. calibrate: metres-per-unit = real height / printed height (1.75 / 0.115 = 15.2)
npm run video:register -- --scene the-pianist --meters-per-unit 15.2
# 3. pin ONLY the first frame to the real camera + lens (one keyframe); the lens during the shot is held by the DSL
npm run video:pin -- --scene the-pianist --shot orbit-25 --start 0
# 4. optimize the camera for a draft CSL (copy one in once with --draft)
npm run video:optimize -- --scene the-pianist --shot orbit-25 --subject subject_1 \
  --draft examples/video/subject-orbit-25deg.draft-csl.json
```

`source/` and `shots/*/keyframes.json` are inputs; everything else is regenerated by the commands above.
Large reconstruction artefacts (`*.npz`, `*.ply`, `*.glb`) stay out of git; reference them from the
server instead.
